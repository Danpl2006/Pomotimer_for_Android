# Pomodoro Timer

Приложение-таймер, реализующее метод Pomodoro для управления временем. Позволяет чередовать интервалы работы и отдыха, вести список задач и настраивать параметры таймера.

## Функционал

- **Таймер** — отсчёт времени работы и перерыва со звуковым уведомлением
- **Подсчёт циклов** — автоматический переход между фазами "работа" → "перерыв"
- **Список задач** — добавление, удаление, отметка выполнения с автосохранением
- **Настройки** — изменение времени работы, перерыва и количества циклов
- **Тёмная тема** — интерфейс выполнен в тёмных тонах

## Технологии

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Сборка:** Gradle (Kotlin DSL)
- **Минимальная версия Android:** Android 7.0
- **Целевая версия:** Android 13
